Программа 1

Upscayl: мелкая картинка станет крупной

Windows 10+macOS 12+Linux
  • Когда нужна. Есть маленькая картинка или скриншот в пикселях, а нужна обложка или печать.
  • Что делает. Увеличивает картинку нейросетью и дорисовывает детали. Работает на твоей видеокарте.
  • Что получишь. Чёткую картинку большего размера вместо «лесенки» из пикселей.
Как поставить
Windows

Скачай файл upscayl-…-win.exe со страницы релизов или с сайта upscayl.org и запусти.

Если Windows покажет синее окно SmartScreen: «Подробнее» → «Выполнить в любом случае». Так написано в README.

macOS

Скачай upscayl-…-mac.dmg, перетащи значок в «Программы». Первый раз открой так: Finder → Программы → правый клик по Upscayl → «Открыть» → ещё раз «Открыть».

Другие способы из README: Mac App Store или команда

brew install --cask upscayl
Linux

Проще всего через магазин приложений (Flathub) или файл .AppImage со страницы релизов: правый клик → Свойства → Права → «Разрешить запуск», затем двойной клик. Есть также пакеты DEB, RPM и в AUR.

⚠️
Пределы. Нужна видеокарта с поддержкой Vulkan: многие встроенные видеокарты не подойдут. Размытое или не в фокусе фото программа не исправит, она помогает именно с маленькими и пиксельными картинками.
github.com/upscayl/upscayl
Программа 2

Recordly: запись экрана, которую не стыдно показать

Windows 10 (сборка 19041+)macOS 14+Linux
  • Когда нужна. Записываешь урок, демо продукта или инструкцию, а сырая запись выглядит скучно.
  • Что делает. Подсказывает, где приблизить кадр по движению курсора, сглаживает курсор, кладёт запись на красивый фон, добавляет камеру в кружке.
  • Что получишь. Готовое видео с приближениями и оформлением без монтажёра.
Как поставить
Windows и macOS

Открой страницу релизов, скачай файл для своей системы и установи как обычную программу.

Linux

Файл со страницы релизов. На Arch и Manjaro:

yay -S recordly-bin
⚠️
Пределы. Приближения программа предлагает сама, но доводить их стоит руками на таймлайне. На Linux нельзя спрятать курсор, а на Wayland при старте записи откроется системное окно выбора экрана.
github.com/webadderallorg/Recordly
Программа 3

Handy: говоришь, а текст печатается

WindowsmacOSLinux
  • Когда нужна. Длинное сообщение, письмо или запрос для Claude, а печатать долго.
  • Что делает. Зажал клавишу, сказал, отпустил: текст появляется в окне, где стоит курсор. Распознаёт речь прямо на компьютере.
  • Что получишь. Текст в любой программе в разы быстрее, чем руками.
Как поставить
Windows

Скачай установщик со страницы релизов или с handy.computer. Или командой:

winget install cjpais.Handy
macOS

Файл со страницы релизов или командой:

brew install --cask handy
Linux

На Debian и Ubuntu скачай .deb и поставь через APT, чтобы подтянулись зависимости:

sudo apt install ./Handy_*.deb

Для вставки текста нужен помощник: на X11 xdotool, на Wayland wtype или dotool. Подробно в README.

После установки: разреши доступ к микрофону и «Универсальный доступ», выбери клавишу в настройках. Модель распознавания скачается один раз, дальше всё работает на компьютере. Для русского выбирай модель Whisper.

Команды brew и winget собирают не авторы Handy, а сообщество: так указано в README.

⚠️
Пределы. На Windows не вставит текст в программу, запущенную от администратора. На Linux с Wayland работает урезанно. На Mac клавиша fn (Globe) срабатывает только на клавиатурах Apple, а Bluetooth-гарнитура может портить звук.
github.com/cjpais/Handy
Программа 4

Agency Agents: готовые роли для Claude Code

Claude CodeCursor, Aider, Windsurf и другие
  • Когда нужна. Хочешь, чтобы Claude Code писал как маркетолог, проверял как тестировщик или думал как дизайнер, а объяснять каждый раз долго.
  • Что делает. Даёт больше 230 готовых ролей в 18 отделах: разработка, дизайн, маркетинг, продажи, поддержка и другие. Каждая роль — файл с инструкцией: кто ты, как работаешь, что считать хорошим результатом.
  • Что получишь. Пишешь «activate Frontend Developer mode», и Claude работает по этой роли.
Как поставить
macOS и Linux

Скачай репозиторий и поставь один отдел, а не всё сразу:

git clone https://github.com/msitarzewski/agency-agents.git
cd agency-agents
./scripts/install.sh --list teams
./scripts/install.sh --tool claude-code --division engineering

Или просто скопируй нужные файлы: cp engineering/*.md ~/.claude/agents/

Windows

Скрипт install.sh написан для macOS и Linux. На Windows скачай репозиторий (зелёная кнопка Code → Download ZIP) и скопируй файлы .md нужного отдела в папку %USERPROFILE%\.claude\agents.

README также предлагает своё приложение Agency Agents для Windows, macOS и Linux: оно ставит роли в Claude Code без командной строки. Ссылка на него есть в самом README.

⚠️
Перед установкой просмотри роли. Это не программы и не «ИИ-сотрудники», а тексты-инструкции, которые меняют поведение Claude. Открой пару файлов отдела и ставь только то, что понятно. Особенно если разрешаешь Claude запускать команды.
Доступ из России. Claude официально не работает в России. Если он у тебя не открывается, подключи BrodSky. 👉 @Brodsky_vpn_bot
github.com/msitarzewski/agency-agents
Программа 5

Hermes Agent: свой ИИ-агент, с которым можно говорить в Telegram

macOSLinuxWindows (PowerShell или WSL2)Android (Termux)
  • Когда нужен. Хочешь агента, который выполняет задачи на компьютере или сервере, а писать ему удобно из Telegram, Discord или терминала.
  • Что делает. Работает в терминале и в мессенджерах, запускает задачи по расписанию. После сложных задач сохраняет решение как навык, чтобы потом повторить. Так заявляют авторы, Nous Research.
  • Что получишь. Помощника, который помнит прошлые разговоры и копит навыки. Если ты раньше пользовался OpenClaw, Hermes перенесёт оттуда настройки.
Как поставить
macOS, Linux, WSL2 
curl -fsSL https://hermes-agent.nousresearch.com/install.sh | bash
Windows

В PowerShell:

iex (irm https://hermes-agent.nousresearch.com/install.ps1)

README предупреждает: антивирус может ругаться на файл uv.exe в папке Hermes. Это менеджер пакетов Python, авторы называют это ложной тревогой.

После установки выбери, какая нейросеть будет думать за агента:

hermes setup

Или только модель: hermes model. Потом запуск: hermes.

⚠️
Сам агент бесплатный, а модель нет. Ему нужен провайдер нейросети: OpenRouter, OpenAI, подписка Nous Portal или своя модель. За запросы к модели платишь провайдеру, если не поднимаешь модель у себя.
🔐
Установка через curl скачивает и сразу запускает скрипт. Проверь, что адрес именно hermes-agent.nousresearch.com. В поиске много сторонних «hermes» с похожими именами, официальный репозиторий один: NousResearch. Агент получает доступ к терминалу и мессенджерам, так что подключай только то, что нужно.
github.com/NousResearch/hermes-agent
