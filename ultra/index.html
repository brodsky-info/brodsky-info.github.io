Шаг 2

Обязательно всё сразу

  • Тебе есть 18 лет.
  • Ты живёшь в стране, где доступен Claude.ai, и не под экспортными ограничениями США.
  • Аккаунту GitHub не меньше 2 лет.
  • Была публичная open-source активность за последние 90 дней.
  • Хотя бы один проект под лицензией, одобренной OSI (например MIT, Apache 2.0, GPL).
  • Ты не сотрудник и не подрядчик Anthropic и не член семьи сотрудника.
