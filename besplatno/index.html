5 подписок на нейросети — минус все пять

Чат-бот, расшифровка голосовых, картинки, разбор почты и озвучка своим голосом. Для каждой платной подписки есть бесплатная замена с GitHub, которая работает прямо на твоём компьютере. Ставить их сам не нужно — говоришь Claude «поставь», и он ставит.

Что понадобится

Claude Code — версия Claude, которая работает с файлами и программами на твоём компьютере (подписка Claude Pro или выше). Через него ставим всё остальное.

Нормальный компьютер. Нейросети работают локально: чем мощнее комп, тем быстрее. Для картинок и озвучки лучше видеокарта или Mac на M-чипе. На слабом ноутбуке будет медленно.

Доступ из России. Claude официально не работает в России. Если он у тебя не открывается, подключи BrodSky: сервис, через который Claude открывается и работает из России. 👉 @Brodsky_vpn_bot

МИНУС 1

Ollama — свой чат-бот без интернета

Запускает языковые модели (Llama, Qwen, Gemma и другие) прямо на твоём компьютере. Переписка никуда не уходит, работает даже без интернета.

Заменяет: платный чат-бот · github.com/ollama/ollama

Скопируй и отправь в Claude Code
Установи Ollama (github.com/ollama/ollama) и скачай модель, которая потянет мой компьютер. Проверь, что она отвечает в терминале, и подскажи, как с ней общаться.
МИНУС 2

Whisper — расшифровка голосовых

Переводит аудио и видео в текст. Час разговора — в готовый текст за минуты, по-русски тоже.

Заменяет: платные сервисы расшифровки · github.com/openai/whisper

Скопируй и отправь в Claude Code
Поставь Whisper (github.com/openai/whisper) или его быструю версию faster-whisper. Сделай команду, чтобы я кидал файл и получал текст на русском.
МИНУС 3

ComfyUI — картинки не хуже Midjourney

Генерация изображений локально: собираешь процесс из блоков, есть тысячи бесплатных моделей и стилей.

Заменяет: Midjourney · github.com/comfyanonymous/ComfyUI

Скопируй и отправь в Claude Code
Установи ComfyUI (github.com/comfyanonymous/ComfyUI) и подходящую для моего компьютера модель для генерации картинок. Запусти и покажи, как сделать первую картинку.

Самая требовательная к железу из пяти.

МИНУС 4

n8n — почта разбирает себя сама

Конструктор автоматизаций: подключаешь почту, и он сортирует письма, отвечает на типовые и присылает сводку.

Заменяет: платные сервисы автоматизации · github.com/n8n-io/n8n

Скопируй и отправь в Claude Code
Установи n8n (github.com/n8n-io/n8n) у меня на компьютере и помоги собрать сценарий: каждое утро разбирать мою почту и присылать мне короткую сводку важного.
МИНУС 5

Chatterbox — озвучка твоим голосом

Даёшь пару фраз своего голоса — и он озвучивает любой текст так, будто говоришь ты.

Заменяет: платные сервисы озвучки · github.com/resemble-ai/chatterbox

Скопируй и отправь в Claude Code
Установи Chatterbox (github.com/resemble-ai/chatterbox). Я дам запись своего голоса на 10–20 секунд — сделай, чтобы он озвучивал мой текст этим голосом.

Озвучивай только свой голос или с согласия человека.
