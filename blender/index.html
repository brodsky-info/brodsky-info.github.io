Claude строит 3Dв Блендере

Блендер — бесплатная программа для 3D. Есть открытый пакет из 94 скиллов, которые учат Claude Code в ней работать: он сам пишет код и строит сцену в твоём запущенном Блендере. Ниже: что поставить, как подключить и чего ждать.

94 скиллалицензия MITпакет и Блендер бесплатные
Простыми словами

Claude не рисует мышкой, он пишет код

  • Скиллы — 94 папки с инструкциями для Claude Code: стили, моделирование, свет, материалы, камера, экспорт.
  • Блендер-директор (blender-director) — главный из них. Сначала собирает план и бриф, потом отдаёт шаги нужным скиллам. Остальные 93 подключает по описанию.
  • Мост — отдельная программа Blender MCP. Через неё Claude отправляет команды в Блендер. Без моста скиллы Блендером управлять не могут.
Что понадобится

Четыре вещи, ключи не нужны

  • Claude Code — на твоей подписке Claude. В обычном чате Claude это не работает.
  • Блендер версии 3.0 или новее. Скачивается бесплатно с blender.org.
  • Python 3.10+ и менеджер пакетов uv — через него запускается мост. Подходит Windows, macOS и Linux.
  • API-ключи не нужны. Они нужны только для необязательных вещей: Sketchfab, Hyper3D, Hunyuan3D, Meshy, Tripo.
Доступ из России. Claude официально не работает в России. Если он у тебя не открывается, подключи BrodSky: через него Claude открывается и работает. 👉 @Brodsky_vpn_bot
Установка

Пять шагов, на любой системе

Шаги 1, 3 и 4 почти одинаковые для всех. В шагах 2 и 5 открой блок со своей системой. Все команды взяты из README репозиториев, ссылки внизу страницы.

  1. Поставь Блендер

    Скачай с blender.org и открой. Нужна версия 3.0 или новее.

  2. Поставь uv

    Это менеджер пакетов Python, он запускает мост командой uvx. README моста предупреждает: без uv дальше не идти.

    macOS
    brew install uv

    Другой способ для macOS и Linux есть в документации uv: docs.astral.sh/uv/getting-started/installation

    Windows
    winget install --id=astral-sh.uv -e

    Или через PowerShell:

    powershell -ExecutionPolicy ByPass -c "irm https://astral.sh/uv/install.ps1 | iex"

    В инструкции пакета скиллов добавлено: после установки проверь, что папка %USERPROFILE%\.local\bin есть в PATH, и перезапусти Claude Code.

    Linux
    curl -LsSf https://astral.sh/uv/install.sh | sh
  3. Поставь аддон-мост в Блендер

    Самый простой путь из README моста:

    uvx mcp-for-blender install-addon

    Или руками: скачай файл addon.py из репозитория ahujasid/blender-mcp, затем в Блендере:

    Edit→Preferences→Add-ons→Install…→addon.py

    Найди в списке «MCP for Blender» и поставь галочку у Interface: MCP for Blender.

    Потом в окне с моделью нажми N, открой вкладку MCP for Blender. Если сервер не запущен, нажми Start MCP Server; в инструкции пакета скиллов эта кнопка названа Connect to Claude. Порт по умолчанию localhost:9876. Блендер оставь открытым.

  4. Поставь 94 скилла

    Скачай репозиторий и скопируй папку .claude/skills в папку .claude/skills своего проекта:

    git clone https://github.com/arjun988/blender-skills.git
cp -r blender-skills/.claude/skills /path/to/your/project/.claude/skills/

    Команда cp работает в macOS и Linux. На Windows сделай то же самое копированием папки в проводнике (или командой Copy-Item в PowerShell): README даёт PowerShell-вариант только для Cursor, для Claude Code на Windows своей команды нет.

    Установка через маркетплейс Claude Code пока не подтверждена: в README сказано, что заявка на листинг проверяется Anthropic, и предложено ставить с GitHub.

  5. Подключи мост к Claude Code

    В README пакета скиллов сказано: Claude Code читает файл .mcp.json в проекте. Добавить сервер можно командой.

    macOS и Linux
    claude mcp add blender uvx mcp-for-blender

    Или в .mcp.json:

    {
  "mcpServers": {
    "blender": {
      "command": "uvx",
      "args": ["mcp-for-blender"]
    }
  }
}
    Windows

    В инструкции пакета скиллов для Windows запуск обёрнут в cmd /c:

    claude mcp add blender cmd /c uvx mcp-for-blender

    Или в .mcp.json:

    {
  "mcpServers": {
    "blender": {
      "command": "cmd",
      "args": ["/c", "uvx", "mcp-for-blender"]
    }
  }
}

    Если видишь ошибку spawn uvx ENOENT, укажи в command полный путь к uvx.exe (его покажет where uvx).

    Ловушка. Если копируешь .mcp.json из репозитория, там запуск написан под Windows (cmd /c). На macOS и Linux замени его на uvx. Первый запуск иногда падает по времени ожидания: повтори. После настройки перезапусти Claude Code.

ℹ️
Пакет скиллов и мост пишут команды немного по-разному (например, название пакета моста и версия Python). Если что-то не заводится, открой официальную инструкцию BLENDER_MCP_SETUP.md: ссылка внизу. Блендер, аддон и кнопку запуска сервера включаешь сам; остальное можно отдать Claude Code фразой ниже.

Первый запрос

Начни с простого

Блендер открыт, сервер моста запущен, Claude Code запущен в папке со скиллами. Отправь:

1

Игрушечный городок

Используй blender-director. Собери в Блендере маленький low-poly городок: пять домиков разного цвета, дорога, пара деревьев, мягкий дневной свет. Делай по шагам и после каждого шага показывай рендер-превью.
2

Уютная комната

Используй blender-director. Собери простую уютную комнату в стиле low-poly: кровать, стол, лампа, окно, тёплый свет. Сначала напиши план, потом строй по шагам.

Если Claude сделал не то, пиши правки короткими шагами: «сделай крышу темнее», «добавь забор». Так работает лучше, чем один большой запрос.

Честно

Что получится, а что нет

Получится

  • Простые сцены: low-poly, стилизованные, изометрия
  • Геометрия, материалы, свет и камера по плану
  • Рендер-превью по ходу работы
  • Подготовка под Unity, Unreal и Godot

Не жди

  • Готовой сцены «одним предложением»
  • Сложных персонажей и живой органики
  • Качественной анимации без правок
  • Что обойдётся без таймаутов и повторов

Сложное лучше дробить на шаги. Доводка остаётся на человеке: Claude даёт основу, ты правишь. Всё держится на одном мосте: если упал аддон в Блендере, остановится всё. Из 94 скиллов выбор идёт по описаниям, поэтому полезно прямо называть blender-director. Полный цикл «идея → готовый экспорт» независимо проверен не был, так что результат зависит от задачи.

Безопасность

Сохрани файл до начала

⚠️
Claude запускает Python-код прямо в твоём Блендере. Соединение с мостом идёт без пароля. Перед сессией сохрани свой .blend, лучше работай в отдельной копии. Ставь только то, чему доверяешь, и не подключай мост, пока он не нужен.
📡
Сбор статистики моста можно выключить переменной DISABLE_TELEMETRY=true. Что именно собирается и как это включается, смотри в README моста и в настройках аддона.
